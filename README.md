# Artificial Intelligence und Reinforcement Learning in Python

This is the code is based on the Udemy course:
*Artificial Intelligence und Reinforcement Learning in Python* by Jan Schaffranek.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/awweber/AI_RL.git
   cd AI_RL
   ```
2. Install the required development packages:
   ```bash
   pip install -r requirements-dev.txt
   ```
   and if you are using Apple Silicon (M1/M2):
   ```bash
   pip install -r requirements_apple.txt
   ```
3. (Optional) If you want to use Jupyter Notebooks, install Jupyter:
   ```bash
   pip install jupyter
   ``` 
## Chapter Overview
The repository is organized into chapters, each containing relevant code and resources:
- **Chapter 1: Einführung**
  - Basic concepts and introduction to AI.
- **Chapter 2: Python Zusatzwissen**
  - Grundlagen von Python, einschließlich Datenstrukturen, Funktionen und Modulen.
- **Chapter 3: Reinforcement Learning Grundlagen**
  - Was sind Agenten, Markov-Entscheidungsprozesse und Belohnungsfunktionen.
- **Chapter 4: Einführung in Gymnasium**
  - Grundlagen der Verwendung von Gymnasium für Reinforcement Learning.
- **Chapter 5: Grundlagen des Deep Learning**
    - Einführung in neuronale Netze und Deep Learning.
- **Chapter 6: Unsere erste KI-Anwendung**
    - Implementierung von Agenten in einer einfachen Umgebung.
    - Training mithilfe von Cross-Entropy-Methode.
- **Chapter 7: Bellman-Gleichungen, Value Iteration, Q-Learning und Policy Interation**
    - Einführung in Bellman-Gleichungen, Value Iteration und Q-Learning.
    - Implementierung von Q-Learning-Agenten.
    - Policy Iteration und deren Anwendung.
- **Chapter 8: Tabular Q-Networks (DQN)**
    - Einführung in Tabular Q-Learning
- **Chapter 9: Einführung in CNN**
    - Einführung in Convolutional Neural Networks (CNNs) und deren Anwendung in der Bildverarbeitung.
- **Chapter 10: Deep Q-Networks (DQN)**
    - Implementierung von Deep Q-Networks (DQN) für komplexe Umgebungen.
- **Chapter 11: DQN-Methoden in ATARI Games**
    - Anwendung von DQN-Methoden auf ATARI-Spiele.
- **Chapter 12: Actor-Critic-Methoden**
    - Einführung in Actor-Critic-Methoden und deren Implementierung.
